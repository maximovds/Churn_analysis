# Customer Churn Analysis

An educational machine learning project exploring customer churn in a telecommunications dataset.

## Project overview

The project investigates customer characteristics and service usage patterns associated with churn, then explores whether machine learning models can help identify customers at risk of leaving.

## What it covers

- Data cleaning and exploratory data analysis (EDA)
- Analysis of churn across customer segments
- Feature preparation and preprocessing
- Training and comparison of classification models
- Model evaluation and discussion of precision and recall
- Potential applications of churn predictions in customer retention

## Tools

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Repository contents

- `Churn.ipynb` — data exploration, modelling, and conclusions
- `telecom_users.csv` — dataset used in the analysis

## Context

This is a course project, not a production machine learning solution. The analysis is exploratory, and observed associations should not be interpreted as proof of causal relationships.
